PINPOINT V1
Mobile-first PWA prototype.

Features:
- World map
- Add pins by positioning map
- Categories and filtering
- 1–5 star ratings
- Visited / Want to visit
- Notes
- One photo per place
- Local on-device storage
- PWA manifest/service worker

Important: shared maps/accounts are intentionally not in V1 yet.
To install as a PWA on iPhone, these files must be served over HTTPS.
